Calendar Management Tool — C#

A simple console-based C# project for managing calendar events.

Features:
- Add an event
- View all events
- Search events by date
- Delete an event
- Prevent duplicate event IDs
- Basic input validation

C# concepts used:
- Classes and objects
- Encapsulation
- Lists
- Methods
- DateTime
- Loops and conditions
- Exception handling

Files:
1. Program.cs
2. CalendarEvent.cs
3. CalendarManager.cs
4. CalendarManagementTool.csproj
